# Refined Average

A cinematic, responsive editorial experience about discipline, psychology and personal growth.

## Experience
- A single-page journey through the philosophy, four-step method and original films.
- Near-black, graphite, warm-white and signature-red visual identity.
- Three.js sculptural hero with a graceful fallback.
- Lenis smooth scrolling, GSAP/ScrollTrigger motion, custom cursor, animated marquee and responsive navigation.
- Reduced-motion and touch-device fallbacks.

## Deployment
Static GitHub Pages site. No build step is required.
